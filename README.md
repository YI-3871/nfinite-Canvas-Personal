# Infinite Canvas Personal

由 [YI-3871](https://github.com/YI-3871) 独立维护的本地 AI 图像创作画布。

项目仓库：[YI-3871/nfinite-Canvas-Personal](https://github.com/YI-3871/nfinite-Canvas-Personal)

## 当前已完成

- Nano Banana 2 图生图编辑、连续多轮图生图编辑的偏粉问题修正与颜色保护。
- API 生成节点支持“关闭 / 自动 / 严格”颜色保护，以及换装、换姿势、场景/光线任务选择，不依赖服务商的模型命名。
- 保留生成原图；颜色校正失败或判断不可靠时回退原图，避免丢失结果。
- 修复传统画布生成成功但 OUTPUT 节点不显示图像的问题。
- 增加可按 Trace ID 排查的本地 API 日志。
- 主侧栏去除旧推广内容，关闭原项目一键更新入口与自动检查。

颜色保护默认关闭，需要在 API 生成节点中选择“自动”或“严格”。场景/光线任务会保留有意改变的光线；颜色保护并不保证每张图片都需要或能够被校正。

## 使用

1. 在本机解压项目并准备运行依赖。
2. Windows 使用 `run.bat`；macOS 参见 [Mac 使用说明](MAC-使用说明.md)。
3. 打开启动窗口显示的网页地址，在“API 设置”中配置自己的服务。
4. 进入传统画布或智能画布开始工作。

详细操作见 [新手运行与使用教程](新手运行与使用教程.md)。API 服务可能收费，本项目不包含服务商额度。
