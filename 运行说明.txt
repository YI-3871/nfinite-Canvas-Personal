Infinite Canvas Personal
维护者：YI-3871
仓库：https://github.com/YI-3871/nfinite-Canvas-Personal

Windows：准备依赖后双击 run.bat，打开启动窗口显示的网页地址。
macOS：请阅读 MAC-使用说明.md。
完整步骤：请阅读 新手运行与使用教程.md。

在网页“API 设置”中填写自己的服务地址、协议和 API Key。
也可以根据需要配置 ModelScope、RunningHub 或本地 ComfyUI。
第三方 API 可能收费，请先确认所用服务的价格和额度。

Nano Banana 2 图生图与多轮编辑的颜色保护已加入画布。
新节点默认关闭颜色保护；需要时选择“自动”或“严格”，原始生成图会保留。

请勿上传 API 密钥、用户素材、生成图片和本地运行日志。
项目不再提供旧的一键更新入口。更新代码前先查看 CHANGELOG.md 和变更记录。
