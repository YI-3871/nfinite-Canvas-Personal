# ADR-0001 · API 生成可选颜色保护

- 状态：已接受
- 日期：2026-09-09
- 关联记录：`IC-20260909-01`、`IC-20260910-02`

## 决策

1. 颜色保护固定在 API 生成节点中，对所有生图模型名称开放，默认关闭；不得依赖上游或中转站返回的模型名称判断是否可用。
2. 任务类型与保护强度必须独立选择并随画布保存。
3. API 原始图始终保留；校正图是附加产物，不覆盖原图。
4. 校正候选必须在留出锚点上改善色差且通过置信度/安全限制。
5. 低置信度、参考图不可用或处理异常时，安全回退到原始输出。
6. `scene_change` 保留用户要求的新场景与光线，不强行对齐旧色彩基线。

## 原因

全局白平衡或无条件矩阵可以减少品红偏色，但也可能破坏有意改变的服装、肤色、光线和背景。因此必须把用户控制、可比较区域、留出评估、强度限制和原图回退结合。

## 约束

- 后续替换算法时不得删除原图保留和安全回退。
- 更改默认开关、适用节点或 `scene_change` 行为属于用户可见设计变更，需要单独记录和浏览器验证。
- 新算法必须有“不重编码相同图”、“低置信度回退”和“保留尺寸/透明度”测试。
