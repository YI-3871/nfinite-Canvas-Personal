# ADR-0002 · 有界磁盘 API Trace

- 状态：已接受
- 日期：2026-09-09
- 关联记录：`IC-20260909-01`

## 决策

1. 每次画布图像 API 请求获得独立 Trace ID。
2. 详细请求、响应、错误、颜色诊断和阶段事件持久化到 `data/task_logs.sqlite3`。
3. 写入使用有界队列；画布 JSON 只保留最多 100 条摘要；完成任务内存缓存最多 200 条且最长 24 小时。
4. SQLite 最大 500MB，超限时从最旧 Trace 清理到约 450MB，并回收文件空闲页。
5. 所有写盘数据先脱敏，不保存凭据、图片二进制或 Base64。
6. UI 按需查询详细 Trace，而不在打开画布时全量加载。
7. 终端日志仅对可预期的重复成功请求降噪，错误不隐藏。

## 原因

只使用终端访问日志无法还原单次 API 任务的完整生命周期；把完整请求长期放入画布 JSON 又会增大内存、保存和同步成本。SQLite 支持按 Trace 查询、重启后持久化和明确的磁盘上限。

## 约束

- 后续扩展视频、LLM 或 ComfyUI Trace 时，继续复用同一脱敏器、Trace 索引和资源上限。
- 新增字段必须先评估是否可能包含凭据、用户文件内容或大体积数据。
- 不得为了“更详细”而存储原始图像 Base64、Authorization Header 或未限长度的响应体。
- 修改剪枝策略时必须保留“运行中任务不因数量上限被删除”的不变量。
