# ADR-0003 · 可审计版本与仓库专用认证

- 状态：已接受
- 日期：2026-09-09
- 关联记录：`IC-20260909-00`

## 决策

1. 使用 Git 提交保存每次实际代码差异，使用单次变更记录保存需求、原因、验证和回退信息。
2. 保留初始版注释标签 `baseline-initial-2026-09-09`，不移动或删除。
3. 功能修改使用 `codex/` 分支，验证后才更新 `main`。
4. 不强制推送、不改写已发布历史；已发布回退优先使用新的 `git revert` 提交。
5. 本机自动推送使用仓库专用、可撤销的 Deploy Key，并将 SSH 命令限定在仓库本地配置中。
6. 网络环境需要时使用 GitHub SSH 443 端口，但仍严格验证官方主机指纹。

## 原因

聊天上下文不是长期审计存储；浏览器已登录也不等于 Git 命令行已获得凭据。仓库专用 Deploy Key 将损害范围限制在一个仓库，而 Git 历史与记录文件可让任何后续任务恢复背景。

## 约束

- 私钥不得进入仓库、聊天、调试包或日志。
- 新电脑不得复用无法确认来源的私钥；应为仓库创建新密钥并撤销旧密钥。
- 变更记录不写实际凭据值、用户素材内容或不必要的个人绝对路径。
- 推送后必须用远程哈希核对结果，并报告未提交的用户文件是否仍存在。
